# Sistema em Java

Projeto desenvolvido em Java com o objetivo de aplicar conceitos de lógica de programação e Programação Orientada a Objetos (POO).

## Sobre o projeto

Este projeto foi desenvolvido durante minha formação em Análise e Desenvolvimento de Sistemas, com foco na aplicação prática dos conceitos estudados em Java.

O sistema utiliza conceitos de Programação Orientada a Objetos, como classes, objetos, métodos, atributos e encapsulamento.

## Objetivos

* Aplicar conceitos de lógica de programação;
* Praticar Programação Orientada a Objetos;
* Desenvolver classes, atributos e métodos;
* Trabalhar com organização e estrutura de código;
* Utilizar Git e GitHub para versionamento do projeto.

## Tecnologias utilizadas

* **Java**
* **Eclipse IDE**
* **Git**
* **GitHub**

## Conceitos aplicados

* Lógica de programação
* Programação Orientada a Objetos
* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Organização de código

## Status do projeto

Em desenvolvimento.
